# Data Analyst Case Studies — Practice Series

A series of real-world, messy datasets solved end-to-end: business problem → data
cleaning → analysis → business recommendation. Built to practice for data analyst
interviews, using genuinely dirty/real datasets — not pre-cleaned Kaggle sets.

## Approach (same for every case study)
1. Start with a real, publicly available messy dataset
2. Define a business problem from a stakeholder's point of view
3. Clean the data — document every issue found and how it was handled
4. Answer business questions using PivotTables / SQL / Python
5. Give a data-backed business recommendation
6. Report a data quality summary (% of data that was trustworthy)

##  Tools Used Across Series
Excel (PivotTables, Charts) · SQL · Python (Pandas) · Power BI

##  Why this series
Most "clean" datasets don't reflect what real data analyst work looks like. This
series intentionally uses unclean, inconsistent, real datasets to practice the skill
that matters most in interviews and on the job: **turning messy data into a
trustworthy business answer.**
